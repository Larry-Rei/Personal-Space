PROJECT 001

《TinyCore Framework 自制框架 & UI 活动业务落地》

独立自研一套与业务无关、高内聚低耦合的 Unity 通用底层基建框架并实现多个 UI 活动业务实例落地，涵盖泛型单例、类型安全事件总线、泛型对象池、双实现资源管理、双层 UI 框架、JSON 存档与编辑器工具链 9 大模块，通过 AI Agent 协同开发，本人主导架构设计与全量测试验证。

UI 框架业务AddressablesAI Agent观察者模式对象池SO 数据驱动UI Toolkit

⚙️ 核心架构与逻辑拆解

  • 框架架构设计：主导设计 9 大通用模块并统一命名空间，业务零耦合、可独立打包复用；基于 AI Agent 完成代码生成与快速迭代，本人主导架构定义、模块拆分及约束设计，确保框架达到可讲解、可复用、可打包的作品级质量。
  • 类型安全事件系统与泛型对象池：基于观察者模式 + 泛型委托构建事件总线，struct 事件零 GC，支持重复订阅去重与广播异常隔离；泛型对象池支持自动扩容、收缩与多池统一管理，消除高频生成销毁的 GC 尖刺。
  • 双层 UI 框架：设计 Panel/Window 双层架构——常驻面板无栈管理、互斥窗口以队列 + 历史栈管理优先级与恢复；对外暴露统一接口，实现类型安全属性传参 (Properties 类)，搭配事件自动解绑与可替换 DOTween 的协程动画接口，杜绝界面销毁后的内存泄漏。
  • 资源管理与数据驱动：抽象 IResourceLoader 统一接口，实现 Resources / Addressables 同步异步加载双实现并运行时无感切换；基于 ScriptableObject 实现"事件 → 音效"配置表，改配置不改代码。
  • UI 活动套件实战落地：基于自研框架和 MVC 模式设计并开发 UI 活动（七日签到、权重转盘抽奖、双线战令、动态背包），以"模拟服务器 Controller + SO 配置表 + 事件广播"架构实现：轮盘赌权重抽奖与 DOTween 减速旋转、战令升级与购买高级战令的自动补发结算、背包 ScrollRect 滚动 + 对象池格子复用 + 新物品红点闭环；验证框架在真实业务下的解耦性与扩展性，实现逻辑、数据与显示的严格分离。
PROJECT 002

《3D 凸体碰撞引擎（SAT + Burst）》

实现基于分离轴定理 (SAT) 的 3D 碰撞系统，支持任意凸多面体碰撞检测与多点接触生成，从 Unity Mesh 自动构建凸体数据，结合 Burst + Job System 实现零 GC 的高性能碰撞计算。

SATHalfEdgeSutherland-Hodgman 裁剪BurstJob SystemNativeContainerUnity Mathematics

⚙️ 核心架构与逻辑拆解

  • 凸体数据结构：基于 HalfEdge 半边结构设计 NativeHull，以原生数组存储顶点/面/半边/平面，支持 O(1) 邻接与支撑点查询，为碰撞算法提供高性能几何数据基础。
  • Mesh 自动构建：实现三角网格到凸体全自动转换（顶点去重、法线分组、共享顶点合并、边界轮廓提取），将碎三角形合并成最小图集，构建完整半边拓扑关系。
  • SAT 双轴检测：面法线 + 边叉积双轴分离轴检测，基于 Minkowski 支撑面筛选有效边轴并处理平行边退化，覆盖面接触与边接触两类碰撞形态。
  • 多点接触生成：基于 Sutherland-Hodgman 裁剪生成最多 24 点接触流形，附带 FeaturePair 特征对标识接触来源，为物理模拟提供稳定接触信息。
  • Burst 性能优化：通过 Burst + Job System 将碰撞计算编译为原生机器码，NativeContainer 全程零 GC，并与普通版对比实测验证性能提升。
PROJECT 003

《绝区零角色状态机复刻》

仿《绝区零》手感复刻的角色状态机与简单战斗系统：双状态机并行驱动位移与连招，数据驱动配置招式手感，事件解耦攻防双方，并配合三层虚拟相机与 Timeline 完成镜头演出。

FSM 有限状态机StateMachineBehaviour 动画事件驱动ScriptableObject 数据驱动Event-Driven 事件解耦对象池CinemachineTimelineNew Input System

⚙️ 核心架构与逻辑拆解

  • 双状态机架构与动画事件驱动：实现基于 FSM 的双状态机角色系统——移动状态机（10 种状态，接管位移 / 闪避 / 转身 / 切人）与连招状态机（攻击 / 技能）两个正交维度并行运行，通过 IState 接口统一生命周期、抽象状态基类承载公共流程，并基于可监听数据字段实现状态变更的订阅式通知。采用 StateMachineBehaviour 让动画反向驱动状态切换，配合输入缓冲，实现丝滑的起步、急停与出招衔接。
  • 数据驱动连招系统与打击感表现：以 ScriptableObject 为载体构建连招数据体系（连段列表 / 单段招式 / 移动参数 / 索敌参数各自独立资产），将伤害、攻击距离、伤害点数、顿帧时长、震屏力度、受击动画名全部外置为可配置数据，使多角色共用同一套逻辑代码。基于动画事件实现“闸门式”衔接（预输入 + 衔接许可），支持冲刺中临时替换起手式并自动还原；打击感由 Cinemachine Impulse 震屏、Animator.speed 顿帧、Time.timeScale 慢动作三者组合实现，并同步粒子播放速度避免穿帮。
  • 事件解耦、资源池化与镜头演出：通过多泛型字符串事件中心实现攻击方与受击方的彻底解耦——攻击者只广播伤害事件，受击方自行判定归属并驱动受击 / 格挡两套动画与掉血计算；构建特效与音效对象池（按“角色 + 名称”两级索引，开局预热、运行时零 Instantiate/Destroy，实例通过生命周期回调自管理回收）；镜头采用 Cinemachine 三层虚拟相机（跟随 / 状态驱动技能机位 / 切人机位）按优先级竞争与 Blend 过渡，大招运镜由 Timeline 录制轨道驱动，并用 Signal 在时间点同步慢动作等演出效果。
PROJECT 004

《Flappy Bird 重构版》

一款经典的 2D 侧翻滚无尽飞行游戏，核心亮点在于引入 xLua 框架对原生 C# 玩法进行了全面重构，实现了“C# 底层稳定承载 + Lua 业务热更”的混合编程架构。

Unity 2DC# / Lua 混合编程xLua 热更框架DOTween对象池优化

⚙️ 核心架构与逻辑拆解

  • xLua 混合架构与生命周期接管：设计并实现 WidgetLuaBehaviour 通用承载组件。通过 Inspector 依赖注入，完成 C# 引用类型向 Lua 虚拟机的零开销映射。接管并转发 Unity 原生生命周期，为每个挂载对象开辟独立的 LuaTable 作用域，彻底解耦底层框架与上层玩法。
  • 核心 3C 与视觉表现的 Lua 化重构：摒弃 Unity 原生物理组件，在 Lua 端运用纯代码计算欧拉积分，精准模拟重力下坠与点击上抛的物理反馈。引入 DOTween 替代原生协程，在 Lua 侧处理序列帧动画与定时器，兼顾了开发的灵活性与平滑的视觉表现。
  • Lua 端对象池与性能防抖：针对无尽生成的管道障碍物，在 Lua 侧独立构建了轻量级的数组缓存池 (Object Pool)。通过状态切换接管高频的 Instantiate/Destroy 操作，大幅规避了跨语言边界下产生的 GC 峰值，保障了跨设备运行的帧率稳定性。

《AI 赋能：极速小游戏全链路开发实践》

一款基于 CPA + CCswitch + Codex 协同工作流构建的经典休闲游戏合集（含 2048、合成大西瓜、三消类）。该项目旨在探索 AI 在游戏原型快速迭代中的极限效能，通过 AI 辅助生成 100% 的核心代码与美术资产。

UnityAI-Driven Workflow (CPA / Codex)C#UGUIPrompt Engineering模块化架构

⚙️ 核心架构与逻辑拆解

  • AI 协同开发流构建与 Prompt 优化：深度整合 CPA + CCswitch + Codex 生产链路，通过高精度的 Prompt Engineering 实现复杂游戏逻辑（如 2048 数值合并算法、合成大西瓜物理堆叠判定、三消矩阵消除逻辑）的自动化生成。将开发重心由底层编码转向架构定义与 AI 代码审查，显著提升原型产出效率。
